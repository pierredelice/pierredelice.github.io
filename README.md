# pierredelice.github.io

Personal academic / professional site for **Pierre Antoine Delice** — AI Engineer,
NLP Researcher, and Data Scientist. The site is generated by a small **Python**
build script and served as static files on GitHub Pages (no runtime, no framework).

## How it works

```
content.py              ← EDIT THIS: all site content (single source of truth)
build.py                ← generator: renders index.html + processes the photo
requirements.txt        ← Pillow (only needed to (re)process the photo)

index.html              GENERATED — do not edit by hand
assets/css/style.css    Styles + light/dark theme (accent #1F4E5F from the CV)
assets/js/main.js        Behavior only: theme toggle, mobile nav, scroll-spy
assets/img/profile.jpg   GENERATED from the source photo (auto-cropped square)
assets/cv/…CV.pdf        Downloadable CV
```

## Make changes (the Python workflow)

1. Edit **`content.py`** — experience, projects, publications, skills, honors,
   contact details, social links, etc. are all plain Python lists/dicts.
2. Rebuild:

   ```bash
   python3 build.py            # regenerate index.html + reprocess the photo
   python3 build.py --no-photo # HTML only (faster; skips Pillow)
   ```

3. Preview locally:

   ```bash
   python3 -m http.server 8000   # open http://localhost:8000
   ```

## Setup (first time)

```bash
python3 -m pip install -r requirements.txt   # installs Pillow
```

## Photo

`content.py → PROFILE["photo_source"]` points at the original headshot.
`build.py` trims the white border, squares it, and writes
`assets/img/profile.jpg`. To use a different photo, change that path and rerun
`python3 build.py`.

## Google Scholar

`PROFILE["scholar"]` is `None`, so the Scholar icon is hidden. Set it to your
Scholar profile URL and rebuild to show it.

## Deploy

Commit and push to `main`. In the repo's **Settings → Pages**, set the source to
`main` / root. The site publishes at <https://pierredelice.github.io>.
